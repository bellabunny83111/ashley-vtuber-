# Ashley Rig Starter v1
Upload the `rig` folder and `assets/ashley/layers` folder to the `ashley-rig-v1` branch. This does not replace the live `main` branch.

This starter establishes Ashley's hierarchical browser rig: root, torso, head, arms, hair and bunny-ear secondary bones. The current flattened Ashley image remains untouched while we integrate transparent PNG layers.

Next patch: connect this rig to `index.html`, then add blink, mouth/lip-sync, heart hands, microphone, hair physics and camera landmark tracking.
